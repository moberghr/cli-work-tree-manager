# Repos page (which repos work knows, and the groups)

`#/repos` (Start's **Repos & groups**, or **Not in the list?** under New worktree's project field): every git repo in the scanned folders, enrolled or not. The scan (`scanForRepos`, `core/worktree/repo-scan.ts`) walks config `scanRoots` (default: the folder holding `worktreesRoot`) two levels deep, stopping at a `.git` folder and skipping a `.git` file (a worktree or submodule), dot-folders, build output and `worktreesRoot` itself. Each row is enrolled (alias, groups, live sessions; "folder gone", or "same folder as" an old duplicate alias), new (an alias suggested from the folder, checked as you type: Add / Ignore), or ignored (config `ignoredRepos`, Unignore). The page notes the cost: every enrolled repo is checked for PRs every 2 minutes. Groups: make one from two or more enrolled repos, add or take out repos (× and + add), delete it. A group's name is final, since its sessions and worktree folders carry it. A change to its repos applies to new sessions, and its instructions file is generated again in a child process (`work config group regen`, Activity kind `groups`). The rules (`core/worktree/repo-rules.ts`, pure: the SPA checks as you type, the demo applies them) refuse a taken alias or group name, a folder that's already enrolled, and a folder name another repo or group already has, since worktree folders are named by it. `core/worktree/repo-admin.ts` writes config.json as raw JSON under its lock (`withFileLock` + `atomicWriteFile`, so keys it doesn't know survive). Removing a repo also takes it out of its groups. Removing a repo, or deleting a group, with live sessions answers 409 naming them, and the page offers **Do it anyway** (`?force=1`). Routes (`repo-routes.ts`): `GET /api/repos` (`ReposWire`), `POST /api/repos`, `DELETE /api/repos/:alias`, `POST /api/repos/ignore`, `POST /api/repos/roots`, `POST /api/groups` (`{name, members, creating}`), `DELETE /api/groups/:name`. Each broadcasts `repos-changed`. The demo keeps a pretend `~/repos` (`demo-repos.ts`), and its `/api/projects` follows it.
