# First run (Welcome)

`#/welcome` (`WelcomeTab`): the dashboard opens on it at load while there's nothing to work on (`needsSetup`, `state/setup.ts`: no config, or no repo and no session), unless the link names a session. Four steps on one page: the folders (your repos folder and where worktrees go, suggested by `suggestFolders`: `~/source/repos` → `~/source/worktrees`, …), your repos (the Repos page inline, once the folders are set), the tools (`checkTools`: git and Claude Code needed, gh and acli optional, each with what to do when it doesn't answer; cached ten minutes, Check again re-asks), and Start (New worktree, enabled once a repo is in and the needed tools answer), plus how to bring work from another computer (`work move`). `core/setup/first-run.ts`; `GET /api/setup` (`SetupWire`, `?fresh=1`), `POST /api/setup {worktreesRoot, reposFolder}` (`saveFolders`: config.json made with `work init`'s defaults when there is none, else only the worktrees root and `scanRoots` change; the worktrees folder is created). The demo is set up already.
